RunVai 2D - NEON ADVENTURE

HOW TO PLAY
- Desktop: press SPACE / UP ARROW to jump (press twice for double jump).
- Desktop: press DOWN ARROW to slide.
- Mobile: tap the JUMP button (tap again in the air for double jump).
- Mobile: tap the SLIDE button to slide under obstacles.
- You can also tap the game area to jump or swipe up/down while playing.

MOBILE SUPPORT
The game layout is optimized for mobile browsers. The original player character
artwork and animation sprite sheets are kept unchanged. Touch controls are shown
during gameplay, and the game canvas keeps its original 16:9 proportions.

GITHUB PAGES
1. Extract this ZIP file.
2. Upload the contents of the RunVai2D_DoubleJump folder to the root of a GitHub repository.
3. Open Settings > Pages.
4. Select Deploy from a branch, choose main and /(root), then Save.
5. Open the published GitHub Pages URL on your phone.

NOTE
Wallet, best score, and unlocked characters are saved in the browser's localStorage.
They are stored separately on each device/browser.

NEW FEATURES
- High Scores: open HIGH SCORES from the main menu to view your personal best and last run.
- Auto Mission: turn the option on/off from the main menu. When enabled, completed missions are automatically rewarded.
- High score, last run, wallet, mission setting, and unlocked characters are saved in this browser's localStorage.
